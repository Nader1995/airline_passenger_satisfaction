# Airline Passenger Satisfaction

A SQL data analysis project exploring the relationship between airline passenger satisfaction/dissatisfaction and different factors related to passengers and their travel experience.

## Dataset

The dataset used in this project is the **Airline Passenger Satisfaction** dataset available on Kaggle:

[Kaggle — Airline Passenger Satisfaction](https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction/data?select=train.csv)

## Purpose

The purpose of this project is to apply and strengthen my SQL skills by working with a real-world dataset.

The main objective is to investigate which factors are associated with passenger **satisfaction or dissatisfaction** using SQL queries and analytical techniques.
